Software Engineer at Breakthrough Apps. I write TypeScript backends and build cloud infrastructure on GCP and AWS, then ship the Flutter apps that run on them.

At Breakthrough:

- Built a TypeScript/Node.js backend to sync subscriptions across App Store, Play Store, Stripe, and RevenueCat
- Built serverless automation on Cloud Functions that cut manual ops work by about half
- Took crash-free sessions from 66% to 94% through structured logging and error handling
- ETL pipelines on BigQuery for billing and analytics data from Stripe and RevenueCat

Before that: built a hyperlocal commerce platform at Locamart, took over product management there, then went solo on a security staff operations portal from spec to deployment.

Got into programming in 2019 after finding the source code of an anime streaming app on GitHub and spending an afternoon trying to understand how it worked.
